# P02 red-team report: "Alcohol does not explain away speeding"

## 1. Target
reports/speeding_confounding.md Summary A/B, §3–§5; README Phase-2 finding 2. Quoted: crude fatal RR 10.0 (8.3–12.2); alcohol "accounts for 9% (7–11%) of the crude log risk ratio — between 4% and 16%"; "69% remains"; all seven blocks RR 4.9 (4.1–5.8); "Among crashes with no alcohol involvement it is 6.5 (5.5–7.8)"; README: "Without alcohol the adjusted risk ratio is 6.5, higher than with alcohol (3.3)"; E-value 7.7; "reverse hypothesis fails too" (6.41 -> 5.62, 4%).

## 2. Reproduction
* From the committed lattice.csv (script 01) and the project's own fit_subset on the data (script 03): crude 10.03, 7-block RR 4.884 (published 4.88), 6 blocks without configuration 5.216 (published 5.22), 69% retained (ln 4.884 / ln 10.03 = 0.688). Shapley alcohol share on the log scale from the lattice: 0.087 (published 9%).
* Stratum RRs 6.54 / 3.29 reproduced in script 03 (published 6.54 / 3.29; ratio 0.50, 0.42–0.61).
* Which stratum gives "3.3": imputed-alcohol stratum "alcohol", from blocks calendar_area + time + light + road_environment + driver_vehicle_mix, with NO crash configuration (strata.csv `blocks` column). The 4.9 uses all seven blocks. E-value arithmetic checked: 4.12 + sqrt(4.12 x 3.12) = 7.71.

## 4. Verdict
**SURVIVES** (confidence: high on the qualitative claim, medium on the exact magnitudes), with wording corrections. No attack removed the core result: exceedance keeps most of its fatal association after alcohol and all recorded blocks, alcohol is a minority share (9% log scale, robust to block partition), and speeding does not explain alcohol (4%, and still <10% under heavy speeding under-recording).

Single most damaging issue: the headline "6.5 vs 3.3" (README) / "6.5" in Summary B is from a five-block model without crash configuration, placed beside the seven-block 4.9. With configuration the figures are 5.4 vs 3.7 (ratio 0.68 instead of 0.50), so the no-alcohol RR is only modestly above the all-sample 4.9 and the alcohol heterogeneity is much smaller.

## 5. Recommended correction
* README finding 2 and Summary B: state that the stratum RRs (6.5, 3.3, 8.0) exclude crash configuration and give the configuration-adjusted values (5.4 no alcohol, 3.7 alcohol) or label "without alcohol the RR is 5–6.5, depending on whether configuration is held fixed"; add "on the relative scale; on the absolute scale the excess is larger with alcohol".
* Replace "after every recorded circumstance" by "after the seven blocks (drugs, distraction and belt use are not in them; adding drugs and distraction gives RR 4.6, 66% retained)".
* State that "9%" is on the log-RR scale (15% on the risk-difference scale) and that alcohol is ~28% of the portion the blocks remove.
* Say explicitly that the QBA is on the crude RR; a half-recorded non-fatal exceedance would roughly halve the adjusted RR as well (about 2.8, assumption-bound).
